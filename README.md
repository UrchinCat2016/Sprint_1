# Sprint_1

Финальный проект первого спринта курса «Автоматизатор тестирования на Python расширенный».

Каждый файл запускается отдельно: `python3 task_1.py`.

- `task_1.py` — общее время в минутах.
- `task_2.py` — исправленный класс `Tester`.
- `task_3.py` — чемпионы мира и поиск страны.
- `task_4.py` — работа со списками задач.
- `task_5.py` — класс `TestCase`.
- `task_6.py` — дополнительное задание: уникальные тикеты по критичности.
- `task_7.py` — дополнительное задание: цифровой корень.

Для выполнения заданий достаточно стандартной библиотеки Python.
